# Diagramas de los programas probabilísticos

- `modelo_a_mermaid.md`: Mermaid del Programa A, con dos ramas: rendimiento final y componente longitudinal.
- `modelo_b_mermaid.md`: Mermaid del Programa B de estados latentes conjuntos de biomasa y nitrógeno aéreo.
- `modelo_a_tikz.tex`: versión TikZ autónoma y compilable del Programa A.
- `modelo_b_tikz.tex`: versión TikZ autónoma y compilable del Programa B.

Los archivos TikZ utilizan `standalone`, `amsmath` y las bibliotecas comunes de TikZ `arrows.meta`, `positioning`, `fit`, `backgrounds` y `calc`.
